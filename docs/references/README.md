# 레퍼런스 이미지 안내

레퍼런스는 **구성과 동작만** 참고한다. 색, 글꼴, 로고, 문구, 그림은 가져오지 않는다.
단, 배경색(#F2F2EB)과 주황(#F54600)은 Heron에서 추출해 쓴다. 종이 질감도 Heron을 참고한다.

## 쓰지 않기로 한 레퍼런스

- 스킬 이름이 오른쪽에서 왼쪽으로 흐르고 숙련도 %를 표시하는 방식 → 쓰지 않음
