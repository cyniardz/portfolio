# 방동훈 Portfolio

바이브 코딩으로 만든 웹 작업과 영상 편집 작업을 한곳에 담은 개인 포트폴리오 웹사이트입니다.
작업물을 담는 그릇이면서, 사이트 자체도 기획, 디자인, 퍼블리싱을 직접 한 작업물입니다.

> 웹과 영상 작업을 한 화면에 담고, 작업물 화면 왼쪽 위 **WEB / VIDEO**로 작업물을 골라 봅니다.

## 기획 의도

- 웹과 영상 두 가지 일을 하므로, 첫 화면에서 두 가지를 모두 보여 주고 작업물만 Web / Video로 나눠 봄
- 작업물을 담는 그릇이면서 사이트 자체로 퍼블리싱 실력을 보여주는 작업물
- 흔한 AI 느낌을 줄이기 위해 색은 두 가지만 쓰고, 움직임은 정해진 곳에만 둠

## 웹과 영상을 한 화면에

| | 내용 |
|---|---|
| 히어로 | 흑연 그림이 찢어지며 얼굴만 컬러, WEB / VIDEO와 작업 여섯 줄 |
| 사용 툴 | 웹 도구 10개와 영상 도구 6개를 점선으로 나눠 모두 표시 |
| 작업물 | 왼쪽 위 WEB / VIDEO를 누르면 웹 5개 / 영상 5개로 바뀜 |

## 화면 구성

| 순서 | 화면 | 내용 |
|---|---|---|
| 1 | 로딩 | "방동훈 Portfolio"가 타자기처럼 쳐지고, 가운데 선이 갈라지며 열림 (스크롤하면 건너뜀) |
| 2 | 히어로 | 찢어지는 그림, WEB / VIDEO 타자기 효과, 작업 여섯 줄 / 오른쪽에 사용 툴(올리면 원래 색)과 Instagram QR |
| 3 | 작업물 | WEB / VIDEO를 골라 보고, 화면에 고정된 채 스크롤하면 작업물이 하나씩 넘어감. 이미지나 [More]를 누르면 자세히 보기 |
| 4 | 스킬 | 영상편집 / 디자인 / 바이브 코딩 / 기획·운영. 연필 스케치에 마우스를 올리면 색이 칠해짐 |
| 5 | About | 작업한 프로젝트를 완료일 순서로 |
| 6 | 한 문장 · 연락 | 눈금 칸이 올라와 문장을 보여 준 뒤 연락 칸으로 끝남 |

## 주요 기능

- **WEB / VIDEO 전환**: 작업물 화면 왼쪽 위 큰 글자로 웹 작업과 영상 작업을 바꿔 봄
- **작업물 고정 스크롤**: 섹션이 화면에 고정된 채 스크롤에 따라 작업물이 넘어감
- **자세히 보기 창**: 작업물 이미지를 누르면 테두리가 안쪽으로 좁아지며 창이 되고, 기간 · 역할 · 도구 · 작업 과정을 보여 줌
- **바로가기 버튼**: [Web] 배포 사이트 · 영상, [Process] 기획서 PDF, [GitHub] 코드 (웹)
- **작업물 데이터 분리**: 작업물 내용은 `data/projects.json` 한 곳에서 관리
- **반응형**: 데스크톱 1440 / 모바일 390 기준
- **접근성**: "동작 줄이기" 설정(prefers-reduced-motion)에서는 움직임을 끔

## 디자인 시스템

| 이름 | 색상 | 용도 |
|---|---|---|
| Background | `#F2F2EB` | 미색 배경 (레퍼런스 Heron에서 추출) + 종이 질감 |
| Accent | `#F54600` | 주황: 커서, 꺾쇠, 눈금, 버튼 |
| Accent Text | `#C83A12` | 작은 주황 글자 |
| Ink | `#1E1E1C` | 본문 글자 |
| Muted | `#77726A` | 보조 글자 |
| Line | `#B3B3AF` | 테두리, 칸 선 |

- 본문: Pretendard
- 로딩 · 작업물 목록 · 제목: 나눔고딕코딩
- 글꼴은 사이트에 쓰는 글자만 남긴 파일로 줄여서 넣음 (`fonts/subset-*.py`)
- 이미지는 WebP, 화면 아래쪽 이미지는 지연 로딩

## 폴더 구조

```
project_05_개인포폴/
├─ index.html          화면 구조
├─ style.css           스타일 (색 · 간격 값은 맨 위 :root)
├─ script.js           로딩, 작업물 탭, 스크롤, 자세히 보기 창
├─ data/projects.json  작업물 데이터 (웹 · 영상)
├─ images/             사진, 로고, 작업물 이미지
├─ process/            작업물 기획서 PDF
├─ fonts/              Pretendard, 나눔고딕코딩 (OFL)
└─ docs/plan.md        기획 문서
```

## 실행 방법

작업물 데이터를 불러오기 때문에 `index.html`을 바로 열면 작업물이 보이지 않습니다.
VS Code의 Live Server 같은 로컬 서버로 열거나, 배포 사이트에서 확인하세요.
