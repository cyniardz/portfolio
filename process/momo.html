빨간 털모자 아기곰 ‘모모’의 굿즈를 파는 일체형 쇼핑몰

기간16시간 (하루 8시간 × 2일)|역할기획 · 디자인 · 개발 (1인)|사용 기술HTML · CSS · JavaScript · Vercel

방동훈

01OVERVIEW

프로젝트 개요

아기곰 캐릭터 ‘모모’를 직접 설정하고, 그 굿즈를 파는 쇼핑몰을 일체형 웹페이지로 만들었습니다.

PC에서는 왼쪽에 이벤트 · 검색 · 퀵메뉴 패널을 두고 오른쪽에 480px 모바일 화면을 붙였습니다. 화면 폭이 1000px보다 좁아지면 왼쪽 패널이 빠지고 모바일 화면만 남습니다.

목표

목록 → 상세 → 찜 · 장바구니까지 실제로 눌러서 이어지는 쇼핑몰

데이터

상품 16개, 카테고리 6개, 배송 · 교환 정책을 JSON 2개 파일로 정리

결과물

메인 1개 + 서브 8개
목록, 상세, 모모 소개, 장바구니, 기획전, 고객센터, 위시, 404

개발

빌드 도구 없이 HTML · CSS · JS로 작성, 로그인 · 찜 · 장바구니는 localStorage에 저장

1920px PC 화면 기준. 왼쪽 패널은 스크롤해도 제자리에 고정됩니다.

일체형 웹페이지란?

PC에서도 모바일 크기의 화면을 그대로 쓰고, 남는 옆 공간에는 검색이나 이벤트처럼 자주 쓰는 기능을 두는 방식입니다.

  • 1모바일 화면을 먼저 만들고 PC는 패널만 더하면 됨
  • 2소품샵 · 캐릭터 굿즈샵에서 자주 보이는 구성
  • 3가로 슬라이드, 카드 목록 같은 앱식 화면을 PC에서도 그대로 사용

03WHY

일체형으로 만든 이유

캐릭터 굿즈샵에는 이 구성이 잘 맞는다고 판단했습니다.

01

화면을
한 벌만 만든다

모바일 화면 하나로 PC와 모바일을 같이 처리하니, 작업 시간이 16시간으로 짧아도 페이지 9개를 끝낼 수 있었습니다.

02

굿즈는
휴대폰으로 산다

캐릭터 굿즈는 SNS를 보다가 휴대폰으로 들어와 사는 경우가 많아, 모바일 화면을 기준으로 잡았습니다.

03

PC의 빈 공간을
패널로 채운다

왼쪽에 이벤트 · 검색 · 퀵메뉴를 고정해, 아래로 내려가 있어도 검색창을 다시 찾을 필요가 없습니다.

04

공통 부분은
한 파일에서

헤더, 푸터, 패널, 로그인 창을 common.js 한 파일에서 넣어서, 메뉴 하나 바꿀 때 9개 페이지를 다 고치지 않아도 됩니다.

누구를 위한 사이트인가

주 사용자

  • · 인스타그램에서 보고 휴대폰으로 바로 들어옴

  • · 상품 상세에서 선물 포장 · 메시지 카드 선택
